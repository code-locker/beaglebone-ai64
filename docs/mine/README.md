# My documents

This is where **I** write and publish my own documents — design notes,
tutorials, blog drafts, experiment write-ups, porting logs, etc.

Unlike `docs/upstream/` (third-party reference material), everything here is my
original work and is covered by the repo's MIT [LICENSE](../../LICENSE).

## Suggested organization

```
docs/mine/
├── notes/        # rough working notes, dated
├── tutorials/    # polished how-tos worth publishing
└── articles/     # long-form / blog-style write-ups
```

## Convention

- One topic per Markdown file, kebab-case names, e.g. `2026-07-14-first-boot-uart.md`.
- Start each file with a title `#` and a one-line summary.
- Prefer Markdown so it renders on GitHub and can be published elsewhere.
